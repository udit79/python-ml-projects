# Python and Machine Learning Projects

This repository contains a selected set of standalone notebook projects and the datasets each notebook needs. Course notes, batch materials, assignment sheets, and unrelated reference files are not included.

## Projects

### Supervised machine learning

- [Credit approval](<./machine-learning/supervised/credit-approval/>): classify loan applications.
- [House price prediction](<./machine-learning/supervised/house-price-prediction/>): predict prices from housing data.
- [Employee turnover](<./machine-learning/supervised/employee-turnover/>): analyze and predict employee turnover.
- [Iris classification](<./machine-learning/supervised/iris-classification/>): classify Iris flower species.
- [Shop Smart](<./machine-learning/supervised/shop-smart/>): classify online shopper behavior.
- [NovaGen](<./machine-learning/supervised/novagen/>): supervised learning with the NovaGen dataset.

### Unsupervised machine learning

- [Smart Cart customer clustering](<./machine-learning/unsupervised/smart-cart-clustering/>): segment customers with clustering.

### Deep learning

- [Text summarizer](<./deep-learning/text-summarizer/>): summarize dialogue using SAMSum data.

## Run a project

Open a project's notebook in Jupyter Notebook or JupyterLab. Keep the notebook and its CSV files together. Each project folder has a short README with its contents.

Python package requirements are not yet documented for every notebook; install the packages imported by the notebook before running it. Some notebooks may need edits for your environment.
